# CommunityHub Foundation MVP

## Goal
Establish the secure platform foundation before building the full social and marketplace experiences.

## Phase 1
- Global user identity
- Community/organization provisioning
- Membership management
- Super Admin and Community Admin roles
- Member role
- Tenant isolation
- PostgreSQL schema and migrations
- API authentication/authorization
- Local Docker development
- GitHub Actions CI

## Phase 2
- Community dashboard
- Member directory
- Announcements
- Events
- Community documents
- Notifications

## Phase 3
- LookAtMe social network
- Follow system
- Posts, comments and reactions
- Media storage
- Moderation

## Phase 4
- Marche marketplace
- Seller shops
- Products/services
- Orders and messaging
- Seller administration

## Product rule
Do not hard-code ACPInc into application logic. ACPInc is the initial tenant used for pilot testing and seed data.
